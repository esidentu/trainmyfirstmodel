# Train My First Model — AI Experiment Lab

A collection of AI and reinforcement-learning experiments built to understand systems by working directly with them.

## What this project is

AI Experiment Lab is where I place technical experiments that help me learn by building. The goal is not only to read about models, agents, or learning systems, but to touch the machinery directly and understand how the pieces behave.

The first highlighted experiment is a reinforcement-learning project: training a Deep Q-Network to play Ms. Pac-Man.

## Why I built it

I learn technical ideas more deeply when I build with them.

Reading about reinforcement learning gives the vocabulary. Implementing an experiment reveals the actual tradeoffs: state, reward, training behavior, feedback loops, and the gap between theory and a working system.

## Learning questions

- What does it mean for a model to learn through trial and error?
- How do reward choices shape behavior?
- Where does training become unstable or unintuitive?
- What changes when the system is observed through code, not only through explanation?
- How can builders use AI responsibly when they understand more of the system underneath?

## Project principles

1. **Build to understand** — use implementation as a learning method.
2. **Explain the system** — document what the experiment is trying to reveal.
3. **Keep the scope honest** — this is an experiment lab, not a production AI product.
4. **Connect technical learning to product judgment** — better understanding should lead to better decisions about what to build.
