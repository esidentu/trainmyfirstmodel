# trainmyfirstmodel

My first reinforcement learning experiment: training a DQN to play Ms. Pac-Man.

This local folder is the workspace for the class assignment. The training run was completed in Colab with these selected choices:

- Exploration epsilon: 0.20
- Training episodes: 100
- Learning rate: 0.0001

Confirmed training summary:

- Completed episodes: 100
- Total decisions: 60,657
- Learning updates: 14,915
- Runtime including demo generation: 253.18 seconds
- Baseline evaluation mean: 492.0
- Trained evaluation mean: 1,182.0
- Score change: +690.0, about +140.24%
